# 0015 Golden bar search above 50% only: pre-registered rules

Status: accepted, 2026-11-22. Written before the search was run.

Harsh: search only windows above 50% (picks the model rates more likely than not). Same method,
data, prices and verdict as ADR 0014 (8 searches: match winner and over/under 2.5 x all leagues and
each league; search 2018/19-2022/23, unseen test 2023/24-2025/26; golden bar only if unseen ROI > 0
with the 99.375% interval above 0), except: windows start at **50% or higher** (lo 0.50-0.90).
